# Prompts — email, publicité et UGC

## Email

```text
Utilise $avatar-direct-response-copywriter en mode EMAIL avec
copywriting/AVATAR.md et copywriting/BRIEF.md.
Type : [broadcast / séquence de N emails]. Objectif : […]. Angle : […].
Produis objet, preheader, corps, CTA et note stratégique. Si c’est une séquence,
donne à chaque email un travail argumentatif distinct.
```

## Publicité

```text
Utilise $avatar-direct-response-copywriter en mode AD avec
copywriting/AVATAR.md et copywriting/BRIEF.md.
Plateforme/placement : […]. Angle testé : […]. Produis 3 variantes fondées sur
3 hooks réellement différents, avec primary text, headline, CTA et concept
visuel. Ne prétends pas que la variation de formulation est un nouvel angle.
```

## Script UGC

```text
Utilise $avatar-direct-response-copywriter en mode UGC_SCRIPT avec
copywriting/AVATAR.md et copywriting/BRIEF.md.
Durée : […]. Profil du créateur : […]. Assets/preuves montrables : […].
Produis hook parlé + visuel, beats horodatés, dialogue naturel, B-roll,
on-screen text, démonstration, preuve et CTA. N’écris pas de faux témoignage.
```
