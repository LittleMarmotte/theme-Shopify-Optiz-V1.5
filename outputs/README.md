# Architecture IA Optiz créée

Les fichiers opérationnels sont installés dans le projet :

- source de vérité : `copywriting/AVATAR.md` ;
- brief et commandes : `copywriting/BRIEF.md`, `copywriting/prompts/` ;
- mode d’emploi : `copywriting/README.md` ;
- skills détectables : `.agents/skills/avatar-direct-response-copywriter`, `.agents/skills/optiz-lp-strategist`, `.agents/skills/optiz-copy-chief`, `.agents/skills/optiz-shopify`.

Les trois premiers forment le workflow de persuasion et de rédaction. `$optiz-shopify` prend ensuite en charge la cohérence de marque et l’intégration dans le thème Shopify.

Commencez par remplir `copywriting/BRIEF.md`, puis lancez le prompt de `copywriting/prompts/RUN_LP_WORKFLOW.md`.

Pour approfondir la recherche consommateur avant rédaction, utilisez `outputs/QUESTIONNAIRE_RECHERCHE_AVATAR_OPTIZ.md`.
